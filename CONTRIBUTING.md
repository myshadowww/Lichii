# Contributing

This Linux desktop fork is maintained at
[myshadowww/Lichii](https://github.com/myshadowww/Lichii). Open
[issues](https://github.com/myshadowww/Lichii/issues) here and target the `desktop`
branch with pull requests. Include the release tag or source commit, AppImage
variant, Linux distribution, hardware and reproduction steps in bug reports.

See the [Linux AppImage guide](docs/linux-releases.md) for our release builds,
the [general build guide](docs/Build.md) for development builds, and the
[coding guidelines](docs/Coding.md) for technical guidance. Keep changes focused,
describe what you tested, and distinguish build checks from gameplay testing.
